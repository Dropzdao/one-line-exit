# The One-Line Exit

Entry for the make.fun bounty **The One-Line Exit**
(https://make.fun/bounty/u-kreutzx-the-one-line-exit-1dc652d1).

`main.py` writes one funny single-line resignation letter to
`/output/entry.txt` — 131 characters, one line, no padding.

Run it with:

```sh
python3 main.py
```
